Resultado matemático da fórmula informada

Informe uma glicemia em mg/dL para calcular.

Fórmula matemática configurada: (glicemia − 100) ÷ 40, arredondando para o inteiro mais próximo (frações de 0,5 arredondam para cima) e sem valores negativos.

Importante: este é apenas o resultado da conta, não uma recomendação para aplicar insulina. Use essa fórmula somente se ela foi confirmada especificamente para você pela sua equipe de saúde. O resultado matemático não determina uma dose segura; siga apenas o plano confirmado pela sua equipe de saúde. O resultado não preenche automaticamente o campo de dose.

Instalar como aplicativo

Adicione o Glucometer à tela inicial para abrir em uma janela própria, como um aplicativo.

Se o botão de instalação não aparecer, abra o menu do navegador e escolha “Instalar aplicativo” ou “Adicionar à tela inicial”, quando disponível.

Os registros ficam neste navegador

O site não exige conta e não envia seus registros de glicose, alimentação ou água para sincronização. Antes de cada alteração, o app tenta manter cópias locais anteriores. Ainda assim, baixe backups JSON regularmente e guarde-os fora do navegador.

Recuperar anotações

Importe um backup JSON do Glucometer ou o arquivo de resgate gerado pelo console. A importação mescla registros por ID e não apaga o diário atual.
